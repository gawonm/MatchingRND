# NTIS 확장 검색 평가 결과

기존 질문 10개를 유지하고 합성 질문 181개를 추가하여 **총 191개**로 비교했다. 추가 질문은 Test의 88개 원문 그룹에서 만들었다. 기술 설명형 60개, 개발 상황형 68개, 조건형 53개다.

| 지표 | 기존 BGE-m3-ko | 기존에 학습한 NTIS 파인튜닝 모델 |
|---|---:|---:|
| Hit@1 | 84.29% | 83.77% |
| Hit@3 | 90.05% | 90.05% |
| Hit@5 | 91.62% | 91.10% |
| Hit@10 | 93.72% | 93.72% |
| MRR@10 | 0.8730 | 0.8712 |

Hit@k는 정답 과제가 상위 k개 안에 포함된 질문의 비율이다. MRR@10은 상위 10개 내 첫 정답의 역순위를 평균한 값이다. 최종 답변 생성 품질을 측정한 결과는 아니다.

## 비교 조건

- 후보 과제 6,580개 전체를 검색했다. Test 과제만 후보로 제한하지 않았다.
- 기준 모델은 `dragonkue/BGE-m3-ko`, revision `7074d66aa46562342193ca4feb3d89bf9dad71b4`다.
- 파인튜닝 모델은 이전 Validation으로 선택한 epoch 1을 그대로 사용했다. 이번 질문으로 모델을 다시 학습하거나 선택하지 않았다.
- 동일한 질문·정답과 고정된 기존/파인튜닝 문서 벡터를 사용했다. 원래 질문 10개와 학습 데이터·모델 파일의 해시를 확인했다.
- 원문 인용, Test 소속, 질문 중복, 질문 형식을 검사했다. 생성에는 GPT-4o-mini를 사용했다. 추가 질문과 정답은 아직 사람이 검수하지 않았다.
- Supabase와 서비스 설정은 변경하지 않았다.

## 해석과 한계

이 확장셋에서는 **파인튜닝의 개선 효과가 확인되지 않았다.** Hit@1과 Hit@5 차이는 각각 정답 질문 1개에 해당한다. 원문 그룹 98개를 단위로 4,000회 paired cluster bootstrap을 수행한 결과, 차이의 95% 구간은 다음과 같으며 모두 0을 포함한다.

| 지표 | 파인튜닝 − 기존 | 95% 구간 |
|---|---:|---:|
| Hit@1 | −0.52%p | −2.76 ~ +1.65%p |
| Hit@5 | −0.52%p | −1.67 ~ 0.00%p |
| MRR@10 | −0.0018 | −0.0146 ~ +0.0106 |

성능 하락을 확정할 근거도 충분하지 않다. 특히 조건형 질문의 Hit@1은 기존 71.70%, 파인튜닝 69.81%로, 다른 유형보다 두 모델 모두 낮았다.

합성 질문은 원문 용어를 일부 포함하는 공통 문장 형식이라 실제 사용자 질문과 분포가 다를 수 있다. 원문 자체에 생략된 내용은 복원하지 않았다. 인용문 일치는 질문 의미와 정답 목록의 완전성을 보장하지 않는다. 예를 들어 전기차 배터리 열폭주 예측 질문에는 다른 과제도 정답일 가능성이 있어 `review_flags.json`에 남겼다. 점수를 본 뒤 정답을 추가하거나 질문을 제외하지 않았다.

## 질문 수정 이력

1차 `expanded_v1`은 307개로 측정했지만, 일부 질문이 과제 검색보다 성능 조건 설명을 요구하거나 적용 대상이 불분명했다. 그 결과와 생성 기록은 보존했다.

이를 확인한 후 **동일한 100개 원문 그룹 전체**에 대해 검색 의도·원문 기술 용어·적용 대상 기준을 보완하여 `expanded_v2`를 만들었다. 구조 및 원문 기반 필터를 통과한 추가 질문 181개를 V2 측정 전에 확정했다. 점수에 따라 원문을 교체하거나 질문을 골라내지는 않았다.

다만 1차 결과를 확인한 뒤 평가 질문 작성 방식을 수정했으므로, V2는 **독립적인 확증 평가가 아닌 탐색적 비교**다. 통계 구간도 합성 질문 편향이나 누락된 대체 정답을 보정하지 않는다. 최종 결론을 강화하려면 사람이 질문과 모든 관련 과제를 검수하고, 별도의 미사용 평가셋으로 다시 확인해야 한다.
