## 현재 RFP와 이전 실험의 관계

Git의 이전 실험 기준 `01307bd`와 현재 버전을 비교했습니다. RFP의 주요 변경은 검색 후 관련성 검사와 검색 실행 코드이며, 파싱·검수 코드는 같았습니다.
검수된 416개 과제의 로컬 PDF 해시를 확인하고 현재 청킹 코드·토크나이저로 다시 청크를 생성했습니다.
1,633개 청크 ID와 본문이 이전 실험과 모두 같았으므로 기존 분할과 학습·평가 라벨을 재사용했습니다.

따라서 이 실험은 새 RFP 원문을 학습한 실험이 아니라, **현재 코드와 같은 원문을 사용하는 임베딩 재학습 실험**입니다.
관련성 검사나 최종 답변 생성 변경의 효과는 이 지표에 포함되지 않습니다.

원래 모델과 이전 LoRA는 변경하지 않습니다. 새 모델을 운영 환경에 배포하지 않습니다.

## 학습과 평가

- Train: 이전 학습에서 검증을 통과한 190개 질문·양성·명시적 음성 예제. 현재 원문에서 근거를 다시 확인하고, 학습 세트 포함 여부와 양성·음성의 그룹 분리를 검사했습니다.
- Validation: 기존 184개 질문. 해당 MRR@10이 높은 epoch을 선택하며, 동률이면 먼저 학습한 epoch을 선택합니다.
- Test: 기존 사용자 질문 5개와 확장 질문 46개(사용자 5개 포함)를 따로 보고합니다.
- 새 학습의 seed는 `20261016`입니다. LoRA rank 8, alpha 16, dropout 0.05, 학습률 2e-5, 2 epoch, 누적 8, temperature 0.05입니다.
- 학습 길이는 384 token이고, 평가에는 전체 청크를 사용하며 최대 길이는 8,192 token입니다.
- GPU 학습·추론은 FP16 autocast를 사용하고, 코사인 계산 전 벡터를 FP32로 정규화합니다. 이번 세 모델은 동일한 계산 조건으로 다시 측정합니다. 이전 저장 지표와의 미세한 차이는 수치 정밀도와 배치 구성에 의해서도 생길 수 있습니다.
- 전체 1,633개 청크의 코사인 점수를 정확 계산하고 과제별 최고 청크 점수로 순위를 매깁니다. 사용자가 확인한 동일 과제만 병합합니다.
- BM25·리랭킹·LLM 관련성 판정·최종 생성 답변은 평가에 포함하지 않습니다.

## 해석 주의

학습·Validation과 확장 질문 41개는 사람이 검수하지 않은 합성 데이터입니다. Test 질문도 이전에 결과를 확인한 재사용 데이터이므로 새 미공개 평가와는 다릅니다.
새 seed로 한 번 재학습한 결과의 작은 차이를 일관된 성능 향상으로 단정할 수 없습니다.
Supabase, 운영 임베딩 모델, 이전 실험 파일을 변경하지 않으며 추가 LLM API 호출도 하지 않습니다.

## 실행 코드

`app/scripts/retrain_rfp_embedding.py`의 `prepare → train → evaluate` 단계를 사용합니다.
기존 학습 checkpoint가 있으면 덮어쓰지 않습니다. 새 실험에는 새로운 `--output` 폴더를 지정해야 합니다.
