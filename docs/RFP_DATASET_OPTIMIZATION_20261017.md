## 당시 해석과 적용 상태

현재 기본값인 ①을 유지한다. 기존 대비 호출 59.6%, 토큰 58.6%, 추정 비용 58.5%, 평균 필터 시간 33.0% 감소했고, 명시 정답 회수는 기존과 같은 3/6이었다. 정답 회수 자체가 50%에 그치므로 충분한 품질이 확인됐다는 뜻은 아니다.

**③의 원문 축소는 이 표본에서 실제로 한 번도 발동하지 않았다.** ③ 및 ③+④ 모두 `excerpt_tasks=0`, 전체 원문 재판단도 0회였다. 따라서 ③과 ①의 차이를 원문 축소의 효과로 해석할 수 없다. 입력 원문이 선택 기준을 통과하지 않은 상태에서 LLM 판정 변동·서버 캐시·응답 속도 차이가 섞인 측정이다. 토큰 예산을 추가로 쓰지 않기 위해 축소 한도를 바꾼 재실행은 하지 않았다.

②는 명시 정답 회수 3/6을 유지했지만 Q7에서 후보를 반환했다. ④와 ③+④는 이 실행에서 2/6을 회수했다. 기본값 변경을 뒷받침하기에는 부족하다. Q21 정답은 ③·④에서도 실제 검토했지만 탈락했다. 따라서 이 누락을 조기 종료 탓으로 단정할 수 없다.

Q3·Q9·Q19의 정답 RFP는 검색 후보에 있었고 ①에서도 검토했지만 A/B 관련 근거 부족으로 탈락했다. 검색 실패보다 현재 엄격한 A/B 필터와 PARTIAL 정답 기준 사이의 차이를 점검할 필요가 있다. 이번에는 판정 기준을 변경하거나 추가 API 검증을 하지 않았다.
