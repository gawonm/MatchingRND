# NTIS 임베딩 학습 비교 결과

기존 NTIS 분할의 6,580개 과제·청크 고정 사본을 사용했습니다. 이 결과는 임베딩 단독 검색 평가이며 운영 RAG나 최종 생성 답변 평가는 아닙니다.
기본 모델에서 새 LoRA를 학습했습니다. 원래 모델과 실험 파일은 보존했습니다.

## 학습과 Validation

이 실험은 Train 전체를 학습한 결과가 아닌 첫 파일럿입니다. 323개 Train 과제의 646개 합성 학습 예제를 사용했습니다.
생성 조건을 통과하지 못한 과제 21개의 초안은 제외했습니다.
Validation 초안은 334개였으나 Train과 동일 질문·긴 연구목표를 공유하는 과제 1개의 질문 2개를 제외하여 332개로 평가했습니다.
이 정리를 완료하기 전에 시작한 학습은 중단·보관하고 기본 모델부터 다시 학습했습니다. 원래 분할과 사용자 Test는 변경하지 않았습니다.

| Validation MRR@10 | 점수 |
|---|---:|
| 기본 모델 | 0.945720 |
| epoch 1 — 선택 | 0.945962 |
| epoch 2 | 0.944289 |

Test 결과로 epoch이나 설정을 바꾸지 않았습니다. 선택된 어댑터는 `adapter_epoch_1/`입니다.

## 해석과 보존

현재 Test 10개는 기본 모델에서도 모두 1위이므로 파인튜닝의 추가 이점을 확인할 여지가 없습니다.
Validation의 차이도 약 0.00024로 작습니다. 전체 NTIS 검색 품질이 향상됐다는 근거로 해석하지 않습니다.
Test를 추가·확장하지 않았습니다. 이전에 만든 추가 작성용 파일 두 개만 삭제했고 기존 `questions.json`은 바이트 단위 해시가 같습니다.
새 모델을 별도 로드하여 만든 6,580개 문서 벡터는 선택된 학습 직후 결과와 최대 절대 오차 0으로 일치했습니다.
RFP·기술나눔 어댑터는 학습 시작점으로 사용하지 않았습니다. 운영 모델과 Supabase는 변경하지 않았습니다.
