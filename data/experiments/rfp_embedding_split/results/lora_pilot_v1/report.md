# RFP 임베딩 파인튜닝 비교 결과

기존 dragonkue/BGE-m3-ko와 동일 모델의 LoRA 학습 버전을 비교했습니다.
학습 190개 / 합성 Validation 184개 / 사용자 Test 5개 / 전체 원문 1,633청크.
Validation MRR@10으로 epoch 2를 선택한 뒤 Test를 평가했습니다.

| 지표 | 기존 모델 | 파인튜닝 |
|---|---:|---:|
| Hit@1 | 40% | 40% |
| Hit@3 | 60% | 60% |
| Hit@5 | 60% | 80% |
| Hit@10 | 80% | 80% |
| MRR@10 | 0.5000 | 0.5067 |

| 질문 | 기존 정답 순위 | 학습 후 정답 순위 |
|---|---:|---:|
| test-001 | 75 | 73 |
| test-002 | 1 | 1 |
| test-003 | 1 | 1 |
| test-004 | 3 | 3 |
| test-005 | 6 | 5 |

개선은 주로 test-005가 6위에서 5위로 진입한 데 따른 것입니다. test-001은 75위에서 73위로 여전히 검색이 어렵습니다.
일부 개선은 확인되지만 전체 품질이 크게 향상됐다고 볼 근거는 부족합니다.

## 질문 원문

- **test-001**: 외부 영상센서를 활용한 주변 환경 인지 및 통합 위험 판단 기술이 있나요?
- **test-002**: AI 활용 엑소좀 다중오믹스 개인맞춤형 난치암 유래 전이암 진단기술이 있을까?
- **test-003**: 3D IC를 만들 때 하부 소자가 손상되지 않도록 하면서 소자를 위로 쌓아 올릴 수 있는 저온 공정 장비 기술이 있나요?
- **test-004**: 차량 안에서 여러 AI 모델이 동시에 돌아갈 때, 서비스 우선순위나 안전정책에 맞춰 각 모델의 실행과 전환을 조절해 주는 기술이 있어?
- **test-005**: 항만 안에서 운행 중인 자율주행 차량이 어떤 임무와 경로로 움직이는지 파악해서, 사고가 나기 전에 미리 예측하고 안전하게 운행하도록 돕는 기술이 있니?

## 실험 조건과 한계

두 모델 모두 동일한 전체 원문 청크를 새로 임베딩하고 정확 코사인 검색으로 비교했습니다.
과제별 최고 청크 점수로 순위를 매기고 사용자가 확인한 동일 과제는 하나로 계산했습니다.
이번 로컬 기존 모델의 정답 순위와 지표는 앞서 측정한 Supabase 기존 모델 결과와 같았습니다.
학습과 Validation은 사람이 미검수한 합성 라벨입니다. Test 5개로 일반 성능을 단정할 수 없습니다.
이 결과는 검색 평가이며, 리랭킹이나 최종 LLM 답변 품질을 측정한 것이 아닙니다.
이번 Test 결과에 맞춰 학습 설정을 반복 선택하지 마세요. 후속 실험에는 새 미공개 Test가 필요합니다.
Supabase와 운영 모델, 원문 청크, 사용자 Test 파일은 변경하지 않았습니다.
