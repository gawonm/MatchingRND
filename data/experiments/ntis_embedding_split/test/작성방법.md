# 국가 R&D 질문·정답 작성 방법

1. 같은 폴더의 [과제 목록](tasks.md)을 열고 제목을 눌러 아래 연구 원문을 읽으세요.
2. 그 과제로 답할 수 있는 질문을 생각해서 [질문 파일](questions.json)의 `query`에 적으세요.
3. 목록의 **정답 document_id**를 `relevant_document_ids`에 복사하세요.
4. 그 질문의 정답임을 보여주는 **원문 문장 그대로**를 `evidence.text`에 복사하세요.

| 항목 | 적을 내용 |
|---|---|
| `query_id` | 서로 다른 질문 번호. 기본값을 써도 됩니다. |
| `query` | 필요한 기술이나 해결하려는 문제로 표현한 검색 질문 |
| `relevant_document_ids` | 정답 문서 ID의 배열. 복수 정답 가능 |
| `evidence.document_id` | 위 배열에 있는 정답 문서 ID |
| `evidence.project_id` | 원래 NTIS 과제번호 |
| `evidence.project_title` | 목록의 과제명 |
| `evidence.filename` | 목록의 원본 파일명 |
| `evidence.text` | 목록의 연구 원문에서 복사한 근거 문장 |

예를 들어 목록의 문서 ID가 `ntis-2050001593`이면 정답 ID에는 이 값을 그대로 씁니다.
`project_id`에는 `2050001593`을 씁니다. 청크 ID나 엑셀 파일명은 정답 ID가 아닙니다.

아래는 구조 설명용 틀입니다. 꺾쇠 부분을 실제 내용으로 바꾸세요.

```json
{
  "query_id": "ntis-test-001",
  "query": "<직접 작성할 질문>",
  "relevant_document_ids": ["<목록에서 복사한 document_id>"],
  "evidence": [
    {
      "document_id": "<동일한 document_id>",
      "project_id": "<원래 과제번호>",
      "project_title": "<과제명>",
      "filename": "ntis_projects_2026_mechanical.xlsx",
      "text": "<연구 원문의 근거 문장 그대로>"
    }
  ]
}
```

- 질문은 Test 목록의 과제로 만드세요. Train/Validation 과제를 Test의 정답으로 추가하지 마세요. 다른 세트에도 같은 정답 과제가 있으면 먼저 알려주세요.
- 같은 제목이어도 연구내용이 다를 수 있습니다. 내용을 읽고 정답을 판단하세요. Test 안에서 여러 과제가 답이 되면 모두 ID를 넣고 근거 항목도 각각 추가하세요.
- 현재 접수 가능한 공고를 묻기보다 관련 연구과제·연구기술을 찾는 질문을 작성하세요. 이 자료는 국가 R&D 연구과제 정보입니다.
- 원문에 이미 생략된 `...` 부분을 상상해서 질문·근거로 쓰지 마세요.
- 10개 빈 항목을 넣어두었습니다. 더 작성하려면 항목을 복사하고 질문 번호를 늘리세요. 사용하지 않은 빈 항목은 삭제하세요.
- 이 파일 작성만으로 파인튜닝이 진행되지는 않습니다. 작성 후 알려주시면 정답 ID·근거를 확인한 뒤 학습·비교 측정 단계로 진행합니다.
