# 기술나눔 질문·정답 작성

이 폴더는 기술나눔용입니다. 기존 RFP 질문과 실험 결과는 `data/experiments/rfp_embedding_split/`에 있습니다.
먼저 같은 폴더의 [Test 기술 목록·원문](technologies.md)을 읽고 질문에 사용할 기술을 고르세요.
직접 수정할 파일은 같은 폴더의 `questions.json` 하나입니다.
빈 질문 10개를 준비했습니다. 필요한 만큼 항목을 복사해서 늘리거나 사용하지 않은 항목은 삭제하세요.
질문 ID는 서로 다르게 지정합니다. 가능한 여러 기술에 걸쳐 질문을 작성하세요.

## 항목별 입력

| 항목 | 입력할 내용 |
|---|---|
| `query_id` | `tech-test-001` 등 서로 다른 질문 ID |
| `query` | 사용자가 실제로 입력할 기술 검색 질문 |
| `relevant_document_ids` | 정답인 개별 기술의 실제 `doc_id` 목록. 모르면 우선 `[]` 유지 |
| `evidence[].document_id` | 해당 근거가 속한 기술의 실제 `doc_id`. 모르면 빈 문자열 유지 |
| `evidence[].technology_title` | 원문에 있는 정답 기술명 |
| `evidence[].filename` | 정답 기술이 소개된 원본 PDF 파일명 |
| `evidence[].pdf_page` | PDF 뷰어 기준 1부터 시작하는 페이지 번호. 인쇄 쪽수와 구분 |
| `evidence[].text` | 질문의 요구 기능을 충족한다는 것을 보여주는 원문 구절 |

ID를 모르면 **질문·기술명·파일명·PDF 페이지·원문 근거**를 먼저 작성하세요.
측정 전에 실제 기술 ID와 연결하고, 연결이 불명확한 항목은 확인합니다.
PDF 전체를 정답으로 지정하는 것이 아니라, PDF에 소개된 개별 기술을 정답으로 지정합니다.
정답이 여러 기술이면 ID 목록과 `evidence` 항목을 함께 추가합니다.

## 형식 예시 — 실제 기술이나 정답을 의미하지 않는 자리표시자

```json
{
  "query_id": "tech-test-001",
  "query": "적용하려는 현장과 해결할 문제, 필요한 기능을 적고 관련 나눔기술을 질문하세요.",
  "relevant_document_ids": [],
  "evidence": [
    {
      "document_id": "",
      "technology_title": "원문에 적힌 기술명",
      "filename": "정답 기술이 실린 원본.pdf",
      "pdf_page": 123,
      "text": "질문에서 요구한 기능이 실제로 명시된 원문 구절"
    }
  ]
}
```

페이지는 숫자로, 모르면 `null`로 둡니다. 문자열은 큰따옴표로 감싸고 마지막 항목 뒤에는 쉼표를 넣지 않습니다.
긴 모범 답변은 필요하지 않습니다. 어떤 기술이 왜 정답인지 확인할 원문 근거가 중요합니다.
기술명 그대로 검색하는 질문 외에 기능·해결할 문제를 풀어 쓴 질문도 포함하세요.
적용 상황을 생략해 여러 분야의 기술이 모두 정답이 될 정도로 넓은 질문은 피하는 것이 좋습니다.

## 현재 상태와 측정 순서

기술나눔 591개를 Train 353개, Validation 178개, Test 60개로 분리했습니다.
기술 ID별 분할은 상위 폴더의 `manifest.json`에 고정했습니다.
질문은 `technologies.md`에 실린 **Test 기술 60개**를 대상으로 작성하세요.
2026-10-15에 작성한 Test 질문 10개로 별도의 기술나눔 LoRA 학습·평가를 완료했습니다.
결과는 상위 폴더의 `results/lora_pilot_v1/report.md`에 있습니다.
기존 결과를 보존하고 추가 질문은 별도 사본에서 작성하는 것을 권장합니다.
RFP용 LoRA 가중치를 기술나눔 전용 파인튜닝 모델로 간주하지 않습니다.

작성 완료를 알려주시면 다음 순서로 진행합니다.

1. 빈 항목, ID·원문 근거, 여러 정답·중복 기술을 확인합니다.
2. 정답 ID가 고정된 Test 기술에 속하는지, 다른 관련 정답이 있는지 확인합니다.
3. 고정된 Train/Validation으로 학습하고, 학습 설정은 Validation으로 선택합니다.
4. 같은 검색 후보와 질문으로 기존 모델·기술나눔 전용 파인튜닝 모델을 비교합니다.

Test 기술과 Test 질문은 학습 데이터로 사용하지 않습니다.
기존 RFP 실험과 Supabase 데이터는 이 파일 작성으로 변경되지 않습니다.
